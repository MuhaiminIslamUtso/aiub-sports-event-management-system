# AIUB Sports Event Management System

A desktop-based sports event management application developed using C# Windows Forms and Microsoft SQL Server.

## Overview

This academic project demonstrates desktop application development, database integration, and Object-Oriented Programming concepts.

## Technology Stack

- C#
- Windows Forms
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Microsoft Visual Studio
- Git and GitHub

## Prerequisites

- Microsoft Visual Studio with the required .NET development workload
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Getting Started

1. Open the solution file (`.sln`) in Visual Studio.
2. Configure the SQL Server database required by the application.
3. Update the database connection string for your local SQL Server instance.
4. Build and run the application.

## Database Configuration

Configure the database and connection string before running the application. Do not publish passwords or sensitive database records.
